# Stuti Swapna Nanda — Data & AI Portfolio

## Deploy with GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository named `stuti-swapna-nanda.github.io`.
3. Upload `index.html` and `README.md` to the repository root (the top-level folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish, then visit https://stuti-swapna-nanda.github.io.

## Update your site
Edit `index.html` directly on GitHub using the pencil icon, or edit it locally and upload the changed file.

## Notes
- This is a static website; it does not require a build step or backend.
- Certification tiles use styled text previews for now. They link to the credential URLs supplied by Stuti. To display certificate images, add image files and update the relevant cards in `index.html`.
- The Talentele internship experience letter is listed separately from certifications.
- The WsCube Tech and Talentele Learning cards link to the LinkedIn profile as a profile fallback, not as direct certificate verification.
- Please check the wording and public details before publishing.
